I planned this website as a two-week project, after Elai Mizrahi and Eshaan Mehta showed me the websites they had made for themselves.

I didn't use a boilerplate. I knew literally nothing about web design, so I found it easier to start from scratch — any existing code was very intimidating. Initially, I would come up with ideas and ChatGPT would translate them into code, but as things got more complicated, ChatGPT struggled to keep up. Luckily, by that point I had accidentally learned a decent amount of HTML and CSS, and W3Schools filled in any other gaps.

During any of the little coding projects I had done in the past, the aspect I enjoyed most was creating an elegant user experience. Web design, being almost entirely user experience, ended up being the most fun project I had done yet — it stopped being a two-week resume booster and became a four-month passion project.

Hosted on Vercel (free). Domain through GoDaddy, ~$15/year.
